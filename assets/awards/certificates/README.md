# 獎狀圖片放置說明 / Certificate images

把獎狀掃描或照片存成下列檔名（JPG 或 PNG 皆可，建議寬度 1600 px 以內），
得獎紀錄頁（awards.html）會自動顯示；檔案不存在時會顯示「獎狀待放」的預留空格。

| 檔名 | 比賽 |
|---|---|
| iyrc-2026.jpg | 國際青少年機器人競賽 2026（IYRC） |
| national-science-fair-66.jpg | 第 66 屆全國中小學科學展覽會 |
| regional-science-fair-2.jpg | 分區科展（第二區） |
| macronix-science-award.jpg | 旺宏科學獎 |
| electronic-design-contest.jpg | 全國電子創意設計競賽 |
| research-paper-contest.jpg | 全國小論文寫作競賽 |
| samsung-solve-for-tomorrow.jpg | 三星 Solve for Tomorrow |

若要使用 PNG，請同時把 awards.html 中對應的 `src` 副檔名改為 .png。
