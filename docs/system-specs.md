# LinkGuard 系統規格（設計目標值）

> 狀態：設計目標／工程估算，標示「待實測」者需場測驗證後覆寫。  
> 對應網站：`index.html` 各單元規格、`CHART_DATA`、方案比較與封包摺疊區。

## 1. LoRa 通訊距離

硬體脈絡：Heltec WiFi LoRa 32 V3（ESP32-S3＋SX1262），預設 L4 Profile（SF9、125 kHz、CR 4/6）。

| 來源 | 數值 | 備註 |
|------|------|------|
| 第 1 次通訊實驗（實測） | 1.59 km | 1590 m |
| 第 2 次通訊實驗（實測） | 1.73 km | 1730 m |
| 第 3 次通訊實驗（實測） | 1.85 km | 1850 m |
| **第 4 次通訊實驗（實測）** | **1.96 km** | **1960 m；目前最大值** |
| 開闊／林區／建築分層 | 待補場測 | 後續依地形分項量測 |

網站圖表單位：公尺 (m)；`CHART_DATA.range` 顯示四次實驗，最大值為第 4 次的 **1960 m**。

## 2. 生存信標節點電池續航

主控 MRT UNO X + LoRa 外掛 + 心率／血氧感測；以 7.4 V 鋰電為基準估算。

| 回報策略 | 設計目標續航 |
|----------|-------------|
| 低頻回報 | **240 h**（約 10 天） |
| 一般回報 | **120 h**（約 5 天） |
| 高頻回報 | **48 h**（約 2 天） |

網站單元規格欄預設顯示：**約 120 小時（一般回報）**。

## 3. 環境感測節點回報週期

| 模式 | 週期 |
|------|------|
| 常態 | **每 5 分鐘** 回報土壤含水／坡度／水位 |
| 異常 | 超過閾值時 **立即額外回報**（不等下一個排程窗） |

與信標共用同一 LoRa 通道，發送窗需錯開以避免碰撞。

## 4. 指揮中心同時追蹤節點數

單一指揮中心、星狀接收、排程錯開前提下：

| 指標 | 設計目標 |
|------|---------|
| 穩定追蹤 | **40** 個節點 |
| 尖峰負載 | **55** 個節點 |
| 實測上限 | **待場測** |

## 5. 地面機器人（UGV）

硬體脈絡：MRT UNO X、麥克納姆輪。

| 項目 | 設計目標 |
|------|---------|
| 續航時間 | **約 40 分鐘**（單次任務、標準鋰電） |
| 越野能力 | **平坦／輕度碎石與室內瓦礫**；軟泥、陡坡、深坑受限（麥克納姆輪特性） |

## 6. 無人機作業距離與飛行時間

| 機型 | 作業距離 | 飛行時間 |
|------|----------------|----------|
| 定翼（廣域掃描） | **約 8 km** | **約 40 分鐘** |
| 四旋翼（近距查證） | **約 1.5 km** | **約 15 分鐘** |

## 7. 封包：頻率、大小、遺失率

### 封包大小

可變長度文字封包（`pktId|pairCode|senderID|type|payload`），依類型約 **30–150 bytes**（Mayday 含 GPS 約 80–150 bytes）；payload 上限 255 bytes。

預設 L4 下空中時間約：30 B → 0.25 s、100 B → 0.65 s、200 B → 1.19 s。詳見網站「資料封包格式」。

### 傳送頻率

| 項目 | 數值 |
|------|------|
| 環境感測常態回報 | **每 5 分鐘** |
| Watchdog | **30 秒** |
| OLED 無互動關閉 | **30 秒** |

### 遺失率（設計目標）

| 情境 | 封包遺失率目標 |
|------|----------------|
| 開闊地、距離 ≤ 實測距離 70% | **&lt; 5%** |
| 林區／建築邊緣、近距離上限 | **&lt; 15%** |

## 8. 單一節點物料成本（BOM）

以生存信標節點（SBN）原型估算，新台幣、小量零售價：

| 項目 | 估算 |
|------|------|
| MRT UNO X | NT$1,000 |
| LoRa 外掛模組＋天線 | NT$250 |
| 心率／血氧感測 | NT$150 |
| 7.4 V 鋰電＋相關 | NT$300 |
| MRT 結構件／線材／雜項 | NT$300 |
| **合計（設計估算）** | **約 NT$2,000／節點** |
| 量產／議價目標 | **約 NT$1,200／節點** |

環境感測節點（SEN）因感測器、雙電池與太陽能配置不同，成本另依模組成本表估算；所有自組節點皆無月租費。

### 對照：衛星通訊器（方案比較用）

| 項目 | 參考值 |
|------|--------|
| 裝置費 | 約 NT$12,000（如 inReach 等級個人裝置） |
| 訂閱 | 約 NT$450–2,000／月（方案而異） |
